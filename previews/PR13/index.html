What is GravityGeophysics.jl? ​

GravityGeophysics.jl does 3D forward modelling and inversion of gravity data for density contrast. It is part of the JuliaGeophysics ecosystem and is driven entirely by small plain-text files: a .xyz survey, block-layout .den models, Key : value control files, and a run folder written next to your data.

If you have a gravity survey and want a density model under it, you are in the right place.

Two ways to invert ​

Both read the same files and return the same kind of result, so you can try one and then the other without changing anything else:

  • Gauss–Newton — the classical approach. Smallness and smoothing hold the model together, and sensitivity or depth weighting stops everything piling up at the surface.

  • Implicit neural representation (INR) — a small coordinate network (Lux.jl) outputs the density of every cell. There is no explicit regularizer; the network's limited capacity is what keeps the model smooth.

Choosing between them explains when each one tends to win.

Install ​

julia
pkg> add GravityGeophysics

You need Julia 1.13.0. Then head to Getting Started to run your first forward model and inversion.
